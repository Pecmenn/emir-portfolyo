# CLAUDE.md

Kişisel portfolyo sitesi (Creative Generalist). React 18 + TypeScript + Vite 5 + Tailwind CSS 3 + GSAP (ScrollTrigger) + Lenis + React Router. Arka uç yok.

- Komutlar: `npm run dev` (http://localhost:5173), `npm run build` (tip kontrolü + `dist/`), `npm run preview`.
- İçerik `src/content/` altındaki JSON dosyalarında (`site.json`, `play.json`, `contact.json`, `ui.json`, `projects/*.json`) ve `/admin` panelinden düzenlenir. Panel ayrı bir React girişidir (`admin.html` → `src/admin/`): GitHub ile giriş sitenin kendi Vercel fonksiyonlarıyla yapılır (`api/auth.js` → GitHub → `api/callback.js`; Vercel ortam değişkenleri `GITHUB_CLIENT_ID` ve `GITHUB_CLIENT_SECRET`, GitHub OAuth App geri dönüş adresi `https://emirokutan.vercel.app/api/callback`), kaydetme GitHub API ile tek commit atar. `src/content.ts` yalnızca türleri tanımlar ve içeriği dağıtır. Her metin `{ tr, en }` çifti; bileşenlerde `useLang().t()` ile okunur. Bileşenlere metin gömme.
- İçeriğe yeni alan eklenirse hem JSON dosyasına, hem `src/content.ts` türüne, hem `src/admin/store.tsx` türlerine, hem de ilgili panel sayfasına (`src/admin/pages/`) eklenmeli.
- Panel yerelde http://localhost:5173/admin adresinde açılır (GitHub girişi olmadan, yerel dosyalarla çalışır; `/api` uçları yalnızca Vercel'de vardır). Giriş yapmadan arayüzü denemek için http://localhost:5173/admin?demo (yalnızca geliştirmede; yerel içerik, kaydetme kapalı).
- Sayfalar: `/` (`src/pages/Home.tsx`) ve `/proje/:slug` (`src/pages/Project.tsx`). Ana sayfa: açılışta fizikle düşen proje parçaları (`src/components/StickerField.tsx`, matter-js), proje indeksi, hizmetler ve iletişim; metinleri ve parça listesi `play.json`'da. İletişim bölümü `src/sections/`, ortak parçalar `src/components/`. Proje galerisindeki kaydırmaya bağlı bloklar `src/components/MotionBlocks.tsx`; açılış/portal yolculuğu `Journey.tsx`, Snack Pack'in oynanabilir bölümü `SnackPackGame.tsx` (matter-js, yalnızca o blok varken yüklenir).
- Kimlik (dal `tasarim/yeni-site`): "Design. Build. Automate." Siyah zemin, krem yazı, şarap vurgu (LinkedIn kapağıyla aynı aile). Ana sayfa (`src/pages/Home.tsx`): açılış, kayan disiplin şeridi, hakkımda, üç alan (Design/Build/Automate), seçili işler (genişleyen kapak şeritleri, `src/components/WorkStrips.tsx`), uçtan uca vaka (şarap bandı), nasıl çalışırım, iletişim; metinleri `play.json` içinde `hero`, `ticker`, `areas`, `work`, `case`, `about`, `process` (panelde Ana sayfa). Çok satırlı başlıklarda satırlar "
" ile ayrılır. Bütün işler `/isler` (`src/pages/Works.tsx`), projenin alanları `areas` (design | build | automate). Hareketler yumuşak: `src/lib/reveal.ts` (`useSoftReveal`) ve index.css içindeki `.soft-line` / `.soft-rise`. Türkçe büyük harf kuralı İngilizce kelimeleri bozmasın diye İngilizce başlıklar ve proje adları `lang="en"` ile işaretlenir. Görseller `node tools/webp.mjs <playwright-core> <genişlik> <kalite> kaynak=hedef.webp` ile WebP'ye çevrilir.
- Sahne motoru (`src/components/Scenes.tsx`): projede `scenes` varsa proje sayfası kapak, giriş ve galeri yerine kaydırmayla oynayan sabit sahneler gösterir (ilk örnek Aloft). Her sahnenin uzunluğu `length` (vh); katmanlar 1600×900 (telefonda `m` alanıyla 400×700) çalışma alanına yerleşir ve `motion` {from, to, start, end, out} değerleriyle [x, y, dönüş, ölçek, opaklık] arasında hareket eder, geri kaydırınca tersine oynar. Katman türleri ve alanları `src/content.ts` içindeki `SceneLayer`'da. Yeşil ekranlı fotoğraflara ekran yerleştirmek için `node tools/sahne-cikar.mjs <fin-*.html> <maske klasörü> <url öneki>` sahne HTML'inden maskeyi ve perspektif matrisini çıkarır. Panelde sahne düzenleyicisi henüz yok.
- Animasyon altyapısı `src/lib/`: `scroll.ts` (tek Lenis örneği + GSAP), `transition.tsx` (proje açılış geçişi `openProject`, diğer sayfa geçişleri `goTo`), `i18n.tsx` (TR/EN).
- Kaydırma Lenis ile yapılır; sayfa içi kaydırma için `scrollToTarget`, `window.scrollTo` kullanma. Animasyonlar `gsap.context` içinde kurulur ve temizlenir.
- Site tek (koyu) temalıdır; menü kaydırınca ince bir çizgi ve buzlu zemin alır.
- Renk token'ları `tailwind.config.js`: `coal` #0D0B0B (zemin), `coal-2`/`coal-3` (yüzeyler), `seam` (çizgi), `cream` #F1E9DE (yazı), `stone` (soluk yazı), `wine` #6B0F17, `wine-deep`, `wine-bright` #B8202F (siyah zeminde büyük yazı ve dolgu), `wine-light` #E0505F (küçük yazı ve hata). Eski `paper`/`ink`/`accent` yalnızca panelde kullanılır. Yazı tipleri (Google Fonts): Anton (`font-display`, `.display` büyük harfli dar başlık), Hanken Grotesk (`font-sans`). Ortak düğme `.btn` / `.btn-wine`, etiket `.tag`.
- Proje görselleri şimdilik picsum yer tutucuları; gerçek görseller `public/images/` altına konup `/images/...` yoluyla verilir. CV dosyası `public/cv/ad-soyad-cv.pdf`.
- Site iki dilli (TR varsayılan, EN); `<html lang>` dil seçimine göre güncellenir.
- Yayın: Vercel (https://emirokutan.vercel.app, proje adı `emirokutan`), `main` dalına her push otomatik yayınlanır (ayarlar `vercel.json`: build `npm run build`, çıktı `dist`, `/admin` ve SPA yönlendirmeleri). Cloudflare Pages kullanılmıyor çünkü `pages.dev` Türk Telekom DNS'inde engelli. Eski Netlify sitesi (`emir-portfolyo.netlify.app`) kullanılmıyor: ücretsiz planı ayda yaklaşık 20 yayına izin veriyor, Netlify OAuth da sonucu yalnızca kendi alan adına iletiyor. Kod değişikliklerini yerelde test edip commit'leri biriktir; kullanıcı "canlıya al" deyince tek seferde push et.
